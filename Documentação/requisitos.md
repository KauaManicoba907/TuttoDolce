# Requisitos

## Usuários

- RF001 — Permitir cadastro de usuários.
- RF002 — Permitir autenticação de usuários.
- RF003 — Permitir gerenciamento dos dados do usuário.
- RF004 — Permitir associação do usuário a um cargo.

## Produtos

- RF005 — Permitir cadastro de produtos.
- RF006 — Permitir edição de produtos.
- RF007 — Permitir ativação e desativação de produtos.
- RF008 — Permitir associação do produto a uma categoria.

## Carrinho

- RF009 — Permitir adicionar produtos ao carrinho.
- RF010 — Permitir alterar a quantidade de produtos.
- RF011 — Permitir remover produtos do carrinho.

## Pedidos

- RF012 — Permitir criação de pedidos.
- RF013 — Permitir visualizar os pedidos realizados.
- RF014 — Permitir gerenciamento do status do pedido.

## Atendimento

- RF015 — Permitir abertura de chamados.
- RF016 — Permitir envio de mensagens em chamados.
- RF017 — Permitir acompanhamento do chamado.
